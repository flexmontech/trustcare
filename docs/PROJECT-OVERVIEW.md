# TrustCare Sales Agent — Project Overview

## Working assumption
This repository relates to a sales or enquiry-support agent for an organisation named TrustCare. Confirm the organisation's actual services and audience before implementation.

## High-level workflow
Enquiry received → information captured → staff-approved criteria applied → agent suggests next step and drafts a response → staff reviews and contacts prospect → outcome recorded.

## Possible MVP
Lead register, enquiry summary, approved FAQ content, follow-up task list, human-approved message drafts, and simple reporting.

## Boundaries
No clinical recommendations, patient triage, eligibility determinations, or autonomous commitments. Do not process health information until privacy, security, access, retention, and vendor requirements have been reviewed.

## Open items
Confirm TrustCare's business type, user roles, enquiry channels, data categories, integrations, and success measures.
