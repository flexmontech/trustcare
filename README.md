# TrustCare Sales Agent

**Status:** Initial concept  
**Owner:** FLEXMON LLC

## Purpose
A sales-support agent concept for TrustCare. The name suggests a care-related organisation, but the exact business model and target users need confirmation before detailed workflows are designed.

## Potential capabilities
- Capture and organise sales enquiries.
- Provide staff with approved service information.
- Qualify enquiries using agreed business criteria.
- Draft follow-up messages for human review.
- Track contact status and next actions.
- Produce basic activity and pipeline summaries.

## Guardrails
Do not provide clinical advice, make care eligibility decisions, promise service availability, or send external messages without authorised human approval. If the project handles patient or client health information, establish the applicable privacy and security requirements before implementation.
